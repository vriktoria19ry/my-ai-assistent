Название переменной SYSTEM_PROMPT само по себе не делает текст системным сообщением, потому что для Python это всего лишь обычная строковая константа. Имя переменной служит исключительно для удобства разработчика: оно подсказывает, какой именно текст хранится внутри, но никак не влияет на то, как этот текст будет обработан нейросетью. Без явной привязки к роли API получит эту строку как обычный набор символов, не понимая её особого назначения.

Роль сообщения задаёт именованный аргумент role внутри конструктора ChatMessage. Именно этот программный параметр (например, role="system" или role="user") сообщает библиотеке gigachat, как именно нужно упаковать текст в JSON-пакет для отправки на сервер. Текст из переменной SYSTEM_PROMPT становится системным сообщением только в тот момент, когда он передаётся в объект:
ChatMessage(role="system", content=SYSTEM_PROMPT)
